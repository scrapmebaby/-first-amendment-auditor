      This is a dependency advisory check, not a full application security audit.

Rendering now uses Three.js 0.186.1 with perspective depth, PBR, shadow maps,
procedural sky/clouds, fog and optional shadow-aware volumetric scattering/bloom.
Light shafts use a distant spotlight approximating sun illumination. There are
no real volumetric cloud simulations, ray-traced reflections or imported assets.

WebGPU software runs initially saturated the device with queued frames. Bounded
GPU work fixed the buildup; the WebGL path also uses nonblocking fences. Browser
frame rates in this software-rendering environment are not representative of
physical GPUs. Both visual quality settings need broader real-device profiling.
Direct file:// remains unverified due to managed Chromium policy; localhost tested.
New assistance/character/fly/bathroom mechanics are not part of this visual release.
PASS: v0.3 campaign regression in Balanced mode: home evidence, loans, destroyed
      equipment, police statement/escape, repairs, demonetization, nine service
      tasks, explicit victory and saved ending reload.
PASS: WebGL 2 atmospheric-to-balanced quality switching without page errors.
PASS: Both GPU APIs disabled: original Canvas renderer boots, moves and changes
      weather without page errors. Unsupported graphics APIs are preflighted.
